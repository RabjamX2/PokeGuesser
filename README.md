# PokèGuesser & Guessing Games

A collection of interactive guessing games (PokèGuesser, Rainbow Six Siege Guesser) built with JavaScript, HTML5, and CSS3.

## Features
- **PokèGuesser**: Test your Pokémon knowledge by guessing Pokémon based on visual and statutory feedback.
- **R6 Guesser**: Guess Rainbow Six Siege operators.

## Quick Start

Simply open `index.html` in your web browser, or launch a local static server:

```bash
# Clone the repository
git clone https://github.com/RabjamX2/PokeGuesser.git
cd PokeGuesser

# Serve locally
npx serve .
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Tech Stack
- HTML5 / CSS3
- JavaScript (ES6+)
